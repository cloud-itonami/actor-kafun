# kafun 花粉

Canonical repository: `cloud-itonami/actor-kafun`. This governed, resident
remediation actor belongs to the Itonami public-operations plane. It proposes
bounded restoration routes; it neither performs forestry work nor owns the
Tamaki artificial-organism evolution loop.

Pollen remediation gate that turns aggregate stand-level pollen burden into restoration
routes. It is assessment-only: no cutting, planting, spraying, person targeting, or
individual health data.

Canonical EDN assets:

- `manifest.edn`, `identity.edn`, `dependencies.edn`
- `data/seed.edn`
- `schema/ontology.kafun.edn`, `schema/schema.edn`
- `lex/remediationVerdict.edn`, `lex/pollenRemediationMap.edn`

Run the full suite with `bb run_tests.clj`.
